# Global Rules

## Code Style

- No dead code. Don't add parameters, fields, or logic that nothing currently uses.
- Don't remove TODO comments unless implementing what they describe.
- Prefer early return over nested ifs when it reduces nesting and improves readability. Invert conditions and return/continue early instead of wrapping logic in deeper blocks.

## Communication

- Be brutally honest. Say plainly if an approach is bad, overcomplicated, or wrong.
