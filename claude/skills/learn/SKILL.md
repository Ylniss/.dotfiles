# Learn

Naucz tematu, który następuje. Użytkownik jest w nim nowy.

## Reguły

1. **Numerowane, logiczne kroki.** Od podstaw do konkretnego przypadku, dopiero
   potem komendy i przykłady.
2. **Proste słowa.** Zdefiniuj żargon przy pierwszym użyciu.
3. **Bez waty, bez wypełniaczy, bez powtarzania tego, co już powiedziano.**
4. **Jednolinijkowe "co robi"** przy każdej wymienionej komendzie, ścieżce,
   fladze lub ustawieniu.
5. **Weryfikuj przed wypisaniem.** Nie wymieniaj komend, pakietów, plików ani
   funkcji z pamięci — sprawdź, że istnieją (context7 dla bibliotek, frameworków
   i narzędzi CLI; inaczej web search, docs, man pages). Oznacz wszystko, co
   niepewne.
6. **Oznacz wagę.** Wyraźnie rozróżnij "wymagane", "opcjonalne" i "można
   pominąć".
7. **Zakończ Q&A.** Krótka sekcja "o czym mogę nie mieć pewności": odpowiedzi na
   2–3 prawdopodobne pytania.
