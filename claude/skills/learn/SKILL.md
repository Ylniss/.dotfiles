# Learn

Teach the topic that follows. The user is new to it.

## Rules

1. **Numbered, logical steps.** Build from primitives to the specific case before showing any commands or examples.
2. **Simple words.** Define jargon the first time it appears.
3. **No fluff, no filler, no recap of what you just said.**
4. **One-line "what it does"** next to every command, file path, flag, or setting you mention.
5. **Verify before listing.** Don't list commands, packages, files, or features from memory — check they actually exist (context7 for libraries, frameworks, and CLI tools; web search, docs, man pages otherwise). Flag anything you're unsure of.
6. **Mark importance.** Clearly distinguish "required" from "optional" from "safe to ignore."
7. **End with Q&A.** Add a short "things I might be unsure about" section answering 2–3 likely follow-up questions.
